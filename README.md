## Общая идея проекта

Платформа имитирует работу городской энергетической системы: умные счётчики передают данные об энергопотреблении, оборудование подстанций отправляет телеметрию, а бизнес-система хранит информацию об устройствах, потребителях и обслуживании.

## Задача

Построить полноценную Data Platform, которая объединяет:
- сбор данных из разных источников;
- потоковую и пакетную обработку;
- CDC;
- Data Lake и Lakehouse;
- DWH и аналитические витрины;
- оркестрацию ETL/ELT;
- подготовку датасетов для последующего обучения ML-моделей.

## Источники данных

Smart Meters - потребление, напряжение, ток, частота

Power Equipment - температура, нагрузка, состояние оборудования, аварии

Business Backend - счётчики, потребители, подстанции, тарифы, обслуживание

External Sources - погода, календарь, исторические данные

## Технологический стек

- Backend: Python, FastAPI
- OLTP: PostgreSQL
- Объектное хранилище: MinIO
- CDC: Debezium + Apache Kafka
- Data format: Parquet
- Lakehouse: Apache Iceberg
- Обработка: PySpark, Spark SQL
- SQL движок: Trino
- DWH: Clickhouse
- Оркестрация: Apache Airflow
- Мониторинг: Prometheus, Grafana
- Трансформации: dbt

## Первый сквозной путь

1. FastAPI и Postgres: одно устройство ->
2. Генератор показаний ->
3. Kafka, один топик ->
4. Spark Streaming дописывает Iceberg-таблицу Bronze, а её Parquet и метаданные лежат в MinIO ->
5. Spark Batch чистит и снимает дубли ->
6. Spark считает потребление по часам ->
7. Одна таблица в ClickHouse
