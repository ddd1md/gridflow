# Выделение ресурсов для контейнеров

Виртуальная машина: 4 vCPU, 16 Гб ОП, 200 Гб постоянная.

PostgreSQL: 1 Гб для маленьких справочников
FastAPI: 0.5 Гб
Генератор: 0.5 Гб при работающем генераторе
Kafka: 1.5 Гб на JVM, и из них heap 768 МБ
MinIO: 0.5 Гб
Iceberg: 0.75 Гб
Spark: 4 Гб, heap драйвер 2 Гб
Clickhouse: 2 Гб внутренний лимит сервера 1.5 Гб

Свободная память около 4 Гб для ОС и под страничный кэш.

Spark и Trino вместе не запускаются. Второй Spark тоже не стартует, пока жив первый.
VM увеличиваем, когда при обычном прогоне растет swap.
